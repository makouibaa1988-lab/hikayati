# حكايتي

تطبيق ويب (PWA) لقصص الأطفال، مقروءة ومسموعة، بالعربية والفرنسية والإنجليزية. يضع الآباء اسم طفلهم وشكله فيصبح بطل القصة، ويمكن رفع صورته لتتحول إلى وجه كرتوني يظهر في رسوم القصة.

## الميزات الحالية
- ست قصص جاهزة (الشجاعة، الرحمة، الصبر، الأمانة، التعاون، حب التعلّم)، لكل قصة غلاف وخمسة مشاهد مرسومة وصفحة نهاية فيها سؤال للطفل، بثلاث لغات.
- البطل يتغير تعبير وجهه وحركته حسب المشهد (فرح، دهشة، شجاعة)، والرسوم فيها حركة خفيفة.
- بطل قابل للتخصيص: الاسم، ولد/بنت (تتغير الأفعال والضمائر حسبه)، لون البشرة والشعر، التسريحة، الملابس، النظارة.
- تحويل صورة الطفل إلى رسم كرتوني **داخل الجهاز**، دون رفع الصورة إلى أي خادم.
- قراءة صوتية بصوت الجهاز مع تلوين الكلمة المقروءة وقراءة متواصلة للصفحات.
- يعمل دون إنترنت بعد أول فتح، ويمكن تثبيته على الهاتف كتطبيق.

## التشغيل
افتح `index.html` عبر أي خادم ويب ثابت، مثلاً:

```
python3 -m http.server
```

ثم افتح http://localhost:8000

## الخطوات القادمة
- توليد قصص جديدة بالذكاء الاصطناعي من داخل التطبيق (يحتاج خادماً صغيراً ومفتاح API).
- أصوات طبيعية للعربية والفرنسية والإنجليزية.
- رسوم بالذكاء الاصطناعي تحافظ على ملامح الطفل في كل المشاهد.
